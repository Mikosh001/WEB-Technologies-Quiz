01 · Web basics Веб негіздері

Internet
Global network of computers.Компьютерлердің әлемдік желісі.
World Wide Web
Linked websites and pages on the Internet.Интернеттегі өзара байланысқан сайттар мен беттер.
Client / server
Browser requests; server responds.Браузер сұрайды, сервер жауап береді.
HTML / CSS / JavaScript
Structure / appearance / behavior.Құрылым / сыртқы көрініс / әрекет.

02 · HTML structure HTML құрылымы

Tag / element
A tag is markup such as <p>; an element includes tags and content.Тег — <p> белгісі; элементке тегтер мен мазмұн кіреді.
<!DOCTYPE html>
Declares an HTML5 document and standards mode.HTML5 құжатын және стандартты режимді білдіреді.
<html>
Root element wrapping the document.Бүкіл құжатты қоршайтын түбір элемент.
<head> / <body>
Metadata / visible page content.Метадерек / бетте көрінетін мазмұн.
<title>
Text shown in the browser tab, not the page heading.Браузер қойындысындағы атау, беттегі тақырып емес.
lang="en"
Declares the page's main language.Беттің негізгі тілін көрсетеді.
charset="utf-8"
Character encoding; supports Kazakh letters.Таңбалар кодталуы; қазақ әріптерін қолдайды.
Viewport meta
Lets responsive CSS use the device width correctly.Адаптивтік CSS-тің құрылғы енін дұрыс қолдануына көмектеседі.
<div> / <span>
Generic block / generic inline element.Жалпы блок / жол ішіндегі жалпы элемент.
<header> / <nav>
Introductory area / navigation links.Кіріспе бөлік / навигациялық сілтемелер.
<main> / <footer>
Primary content / closing information.Негізгі мазмұн / қорытынды ақпарат.
<section> / <aside>
Thematic section / related supporting content.Тақырыптық бөлім / қатысты қосымша ақпарат.

03 · Text, links & images Мәтін, сілтеме және сурет

<h1> to <h6>
Headings from highest to lowest level.Ең жоғарыдан ең төменге дейінгі тақырыптар.
<p> / <br> / <hr>
Paragraph / line break / thematic break.Абзац / жаңа жол / тақырыптық бөліну.
<a href="...">
Clickable link; href is its destination.Басылатын сілтеме; href — баратын мекенжайы.
href="#gallery"
Jumps to id="gallery" on the same page.Сол беттегі id="gallery" элементіне апарады.
<img src="..." alt="...">
src is the image path; alt describes the image.src — файл жолы; alt — сурет сипаттамасы.
<figure> / <figcaption>
Media group / its caption.Сурет тобы / оның түсіндірме жазуы.
loading="lazy"
Defers an off-screen image until needed.Экраннан тыс суретті қажет болғанда жүктейді.
aria-label / aria-labelledby
Accessible name / name taken from another element's ID.Қолжетімді атау / басқа элементтің ID-інен алынған атау.
tabindex="0"
Makes an element reachable with the Tab key.Элементке Tab пернесімен жетуге мүмкіндік береді.
Favicon
Small browser-tab icon, often linked with rel="icon".Браузер қойындысындағы шағын белгі, әдетте rel="icon" арқылы қосылады.

04 · Lists & tables Тізімдер мен кестелер

<ul> / <ol> / <li>
Bulleted list / numbered list / one list item.Маркерлі тізім / нөмірленген тізім / бір тізім элементі.
<table> / <tr>
Table / one table row.Кесте / бір кесте жолы.
<th> / <td>
Header cell / data cell. Neither tag means a whole row or column.Тақырып ұяшығы / дерек ұяшығы. Екеуі де тұтас жол не баған емес.
colspan / rowspan
One cell spans columns / rows.Бір ұяшық бірнеше бағанды / жолды қамтиды.
<caption>
Title or description of the whole table.Бүкіл кестенің атауы не сипаттамасы.
<thead> / <tbody> / <tfoot>
Header / main / footer row groups.Тақырып / негізгі / қорытынды жолдар тобы.
scope="col" / scope="row"
Header labels a column / a row.Тақырып бағанды / жолды сипаттайды.
border-collapse: collapse
Joins adjacent table-cell borders into single lines.Көршілес ұяшық жиектерін бір сызыққа біріктіреді.

05 · Forms & attributes Формалар мен атрибуттар

<form>
Groups user-input controls.Пайдаланушы енгізу элементтерін топтайды.
<label for="x">
Labels the control whose id="x".id="x" болатын өрісті атайды.
id / name
Unique page identifier / key used in submitted form data.Беттегі бірегей атау / жіберілетін форма дерегінің кілті.
type="text" / type="email"
General text / email-format input.Жалпы мәтін / пошта пішіміндегі енгізу.
type="radio"
One choice from inputs sharing the same name.Бірдей name бар топтан бір ғана таңдау.
type="checkbox"
Independent choices; several may be checked.Тәуелсіз таңдаулар; бірнешеуін белгілеуге болады.
<select> / <option>
Drop-down control / one choice in it.Ашылмалы тізім / ондағы бір нұсқа.
value
Data value associated with an input or selected option.Input не таңдалған option үшін қолданылатын дерек мәні.
<textarea>
Multi-line text field; resize: none stops manual resizing.Көпжолды мәтін өрісі; resize: none өлшемін қолмен өзгертуді тоқтатады.
placeholder / required
Temporary hint / must be filled before normal submission.Уақытша нұсқау / жіберу алдында міндетті түрде толтыру.
maxlength
Maximum number of characters the user can enter.Енгізуге болатын таңбалардың ең көп саны.
selected / disabled
Initially chosen option / unavailable option.Бастапқыда таңдалған / таңдауға болмайтын нұсқа.
<button type="submit">
Starts form submission after browser validation.Браузер тексергеннен кейін форманы жіберуді бастайды.

06 · CSS & selectors CSS және селекторлар

Inline / internal / external CSS
style="..." / <style> / linked .css file.Элемент ішіндегі style / HTML ішіндегі style тегі / бөлек CSS файлы.
<link rel="stylesheet" href="...">
Connects an external CSS file in <head>.Сыртқы CSS файлын <head> ішінде қосады.
p / .card / #title / *
Element / class / ID / all-elements selectors.Элемент / класс / ID / барлық элемент селекторлары.
Class / ID
Class is reusable; an ID should be unique on the page.Класс қайталанады; ID бетте бірегей болуы керек.
Basic specificity
Inline style > ID > class > element, assuming normal competing rules.Қарапайым жағдайда inline style > ID > класс > элемент.
.radio label / .grid > .item
Any descendant label / direct child item.Ішіндегі кез келген label / тікелей бала item.
li + li / a, button
Immediately following sibling / one rule for both selectors.Бірден кейінгі көрші / екі селекторға ортақ ереже.
[aria-current="page"]
Elements with that exact attribute value.Атрибутының мәні дәл сондай элементтер.
:hover / :focus-visible
Pointer over element / visible keyboard focus.Меңзер үстінде / пернетақта фокусы көрінгенде.
:nth-child(even) / ::after
Even-positioned siblings / pseudo-element after content.Жұп орында тұрған көршілер / мазмұн соңындағы псевдоэлемент.
:root / var(--sea)
Document root for CSS variables / read one variable.CSS айнымалылары сақталатын түбір / айнымалыны қолдану.

07 · Text, color & box model Мәтін, түс және аралықтар

color / background-color
Text color / element background color.Мәтін түсі / элементтің фон түсі.
HEX / RGB / RGBA / HSL
Color formats; RGBA includes an alpha transparency value.Түс жазу форматтары; RGBA ішінде мөлдірлік мәні бар.
font-family / font-size / font-weight
Typeface / text size / text thickness.Қаріп түрі / мәтін өлшемі / мәтін қалыңдығы.
px / em / rem
CSS pixels / local font-relative / root font-relative units.CSS пикселі / жергілікті қаріпке / түбір қаріпке тәуелді бірлік.
text-align: right / center
Aligns text inside the box, not the box itself.Мәтінді қорап ішінде туралайды, қораптың өзін емес.
line-height: 1.6
Line height is 1.6 times the font size.Жол биіктігі қаріп өлшемінің 1.6 есесі.
letter-spacing / text-transform: uppercase
Space between letters / show capital letters.Әріп аралығы / бас әріппен көрсету.
text-decoration: none
Removes decoration such as a link underline; link still works.Сілтеменің астындағы сызықты алып тастайды; сілтеме жұмыс істейді.
white-space: nowrap / list-style: none
Stops normal text wrapping / removes list markers.Мәтіннің жаңа жолға бөлінуін тоқтатады / тізім маркерлерін алып тастайды.
Box model
Content → padding → border → margin, from inside out.Іштен сыртқа: мазмұн → padding → border → margin.
padding / margin
Inner space / outer space.Ішкі аралық / сыртқы аралық.
padding-left / margin-top
Inner left space / outer space above the element.Сол жақ ішкі аралық / элемент үстіндегі сыртқы аралық.
padding-block / margin-inline
Top-and-bottom inner space / side outer margins in normal writing.Үстіңгі-астыңғы ішкі аралық / әдеттегі жазылымда екі жақтағы сыртқы аралық.
margin: 0 auto
Often centers a width-limited block horizontally.Ені шектелген блокты көбіне көлденең ортаға қояды.
box-sizing: border-box
Declared width includes padding and border.Берілген енге padding пен border кіреді.
border-radius / box-shadow
Rounded corners / shadow around the box.Дөңгелек бұрыштар / қорап айналасындағы көлеңке.
width: 100%; max-width: 300px
Uses available width but never exceeds 300px.Қолдағы енді алады, бірақ 300px-тен аспайды.
display: block / inline-block
New-line block / inline placement with width and height.Жаңа жолдағы блок / жол ішінде тұрып ен-биіктік алатын блок.
min-height: 100vh
At least one viewport tall.Ең аз биіктігі экранның көрінетін биіктігіне тең.
clamp(min, preferred, max)
Responsive value kept between minimum and maximum.Ең аз және ең көп шек арасындағы адаптивті мән.
min(a, b)
Uses the smaller of two values; useful for responsive container widths.Екі мәннің кішісін алады; адаптивті контейнер еніне пайдалы.

08 · Position & effects Орналасу және әсерлер

position: static
Default normal document flow.Әдепкі қалыпты құжат орналасуы.
position: relative
Stays in flow; can shift from its own place.Орнын сақтайды; өз орнына қатысты жылжи алады.
position: absolute
Positions against the nearest positioned ancestor.Position берілген ең жақын ата-анаға қатысты орналасады.
position: fixed
Usually stays at one viewport position while scrolling.Бет айналғанда әдетте экрандағы орнын сақтайды.
float: left/right / clear: both
Float box to a side / move below floats on both sides.Қорапты бір жаққа шығару / екі жақтағы float астына түсіру.
button:hover / a:hover
Style while the pointer is over a button / link.Меңзер батырма / сілтеме үстінде болғандағы стиль.
cursor: pointer
Shows a hand pointer over a clickable element.Басылатын элемент үстінде қол белгісін көрсетеді.
transition / transform: scale(1.05)
Smooth change / visually enlarge by 5%.Біртіндеп өзгеріс / көзге 5% үлкейту.
object-fit: cover
Fills the image box, preserving proportions and possibly cropping.Пропорцияны сақтап қорапты толтырады; сурет қиылуы мүмкін.
object-position / overflow: hidden
Controls visible image area / clips content outside the box.Суреттің көрінетін бөлігін басқарады / қораптан асқанды жасырады.
opacity: 0 / display: none
Transparent but keeps layout space / hidden with no layout space.Мөлдір, орны сақталады / жасырын, орны алынған.
z-index / inset: 0
Stacking order / zero offsets on all four sides.Қабаттасу реті / төрт жақтағы ығысуды нөл ету.
aspect-ratio: 16/10
Keeps a 16:10 width-to-height proportion.Ен мен биіктіктің 16:10 қатынасын сақтайды.
linear-gradient
Smooth transition between colors, often used as an image overlay.Түстер арасындағы біртіндеп ауысу, көбіне сурет үстіндегі қабатқа қолданылады.

09 · Flexbox Flexbox

Flexbox
One-dimensional layout: row OR column.Бір өлшемді орналасу: жол НЕМЕСЕ баған.
display: flex
Parent becomes a flex container; direct children become flex items.Ата-ана flex контейнері, тікелей балалары flex элементі болады.
Main / cross axis
Primary layout direction / direction perpendicular to it.Негізгі орналасу бағыты / оған перпендикуляр бағыт.
flex-direction: row / column
Horizontal / vertical main axis.Көлденең / тік негізгі ось.
row-reverse / column-reverse
Same axes, but the visual item direction is reversed.Ось сол күйінде, бірақ элементтердің көрінетін бағыты кері болады.
justify-content / align-items
Align on main axis / cross axis.Негізгі осьте / оған перпендикуляр осьте туралау.
space-between
First and last items at the ends; space between items.Алғашқы және соңғы элемент шетте, араларында бос орын.
flex-wrap: wrap
Items can continue on a new row or column.Элементтер келесі жолға не бағанға өте алады.
gap: 20px
20px spacing between items, not outside the container.Элементтердің арасында 20px, контейнер сыртында емес.
flex-grow / flex-shrink
How an item expands / shrinks when space changes.Орын өзгергенде элементтің ұлғаюы / кішіреюі.
flex-basis
Initial main-axis size before grow or shrink.Ұлғаю не кішірею алдындағы негізгі осьтегі бастапқы өлшем.
flex: 1 1 0
Shorthand: grow 1, shrink 1, basis 0; useful for equal cards.Қысқа жазылым: grow 1, shrink 1, basis 0; тең карточкаларға пайдалы.
align-self / order
Cross-axis alignment of one item / visual item order.Бір элементтің көлденең осьтегі туралануы / көрінетін реті.
margin-top: auto
In a column flex container, pushes an item toward the bottom.Бағандық flex ішінде элементті төмен итереді.

10 · CSS Grid CSS торы

Grid
Two-dimensional layout: rows AND columns.Екі өлшемді орналасу: жолдар ЖӘНЕ бағандар.
display: grid
Parent becomes a grid container; direct children become grid items.Ата-ана Grid контейнері, тікелей балалары Grid элементі болады.
Track / cell / line / area
Row or column / one unit / dividing boundary / rectangular region.Жол не баған / бір ұяшық / бөлетін сызық / тікбұрышты аймақ.
grid-template-columns / grid-template-rows
Column widths / row heights.Баған ені / жол биіктігі.
1fr 2fr
Two tracks share available space in a 1:2 ratio.Екі бөлік бос орынды 1:2 қатынасында бөледі.
repeat(3, 1fr)
Three equal flexible tracks.Ені бірдей үш икемді бөлік.
minmax(0, 1fr)
Track can shrink toward zero and grow to one fraction.Бөлік 0-ге дейін кішірейіп, 1fr-ге дейін өсе алады.
auto / min-content / max-content
Adaptive / smallest intrinsic / largest unwrapped intrinsic size.Бейімделетін / табиғи ең кіші / жолға бөлінбеген ең үлкен өлшем.
fit-content(300px)
Fit content up to the given limit.Мазмұнға сай өседі, бірақ көрсетілген шектен аспайды.
gap / row-gap / column-gap
All gaps / gaps between rows / between columns.Барлық аралық / жолдар арасы / бағандар арасы.
grid-column: 1 / 3
From grid line 1 to line 3: two columns.1-сызықтан 3-сызыққа дейін: екі баған.
grid-row / grid-area
Item's row position / position or named area.Элементтің жолдағы орны / орны не атаулы аймағы.
grid-template-areas
Named layout map, such as header / sidebar / main / footer.header / sidebar / main / footer сияқты атаулы орналасу картасы.
justify-items / align-items
All items horizontally / vertically inside their cells.Барлық элементті ұяшық ішінде көлденең / тігінен туралау.
justify-content / align-content
Whole grid horizontally / vertically when extra space exists.Артық орын болса бүкіл Grid-ті көлденең / тігінен туралау.
justify-self / align-self
One item horizontally / vertically inside its cell.Бір элементті ұяшық ішінде көлденең / тігінен туралау.
grid-auto-rows: 220px
Height of rows created automatically.Автоматты жасалған жолдардың биіктігі.
Grid + Flexbox
Grid for the outer layout; Flexbox can align content inside a grid item.Сыртқы құрылымға Grid, ұяшық ішіндегі мазмұнға Flexbox қолдануға болады.

11 · Responsive & Bootstrap Адаптивтік дизайн және Bootstrap

@media (max-width: 680px)
Rules apply at 680px viewport width or narrower.Экран ені 680px не одан аз болғанда ережелер қолданылады.
Breakpoint
Screen-width threshold where layout rules change.Орналасу ережесі өзгеретін экран ені шегі.
prefers-reduced-motion
Respects the user's request for less animation.Пайдаланушының анимацияны азайту қалауын ескереді.
repeat(auto-fit, minmax(200px, 1fr))
Fits as many minimum-200px grid columns as space allows.Ең аз ені 200px бағандардың сыйғанынша орналастырады.
Bootstrap .container / .row
Responsive wrapper / grid row; put columns inside the row.Адаптивті контейнер / тор жолы; бағандар row ішінде болады.
.col-md-6
Six of twelve grid columns from medium screens upward.Орта және кең экранда 12 бағанның 6-уы.
.row-cols-lg-3
Three columns per row from large screens upward.Кең экраннан бастап бір жолда үш баған.
.d-flex / .flex-md-row
Turns on Flexbox / uses row direction from medium screens.Flexbox қосады / орта экраннан бастап жол бағытын қолданады.
.ms-auto / .g-3
Auto start-side margin / grid gutter spacing.Бастапқы жақтағы auto margin / тор элементтерінің аралығы.
Bootstrap navbar toggler
